SEARULEA CLIENT PRESENTATION TEMPLATE

Files
- SEARULEA_Ready_to_Fill_Template.pptx: 57-slide fill-and-go library with multiple variants for every common page type.
- SEARULEA_Ready_to_Fill_Template.potx: reusable PowerPoint template version of the fill-and-go library.
- SEARULEA_Client_Presentation_Template.pptx: editable 23-slide starter deck and layout library.
- SEARULEA_Client_Presentation_Template.potx: reusable PowerPoint template; open it to create a new presentation.
- Fonts/: Lora and DM Sans brand fonts.

How to use
1. Install the fonts in the Fonts folder before opening the deck.
2. For the fastest workflow, open the Ready-to-Fill PPTX and duplicate the closest page variant.
3. Replace all bracketed text, REPLACE IMAGE labels and example chart/table data.
4. Use Save As for each new presentation, or install/open the matching POTX as a reusable template.
5. Keep one Lora statement per slide; use DM Sans for body copy, labels and data.
6. Keep the official logo and motif proportions unchanged.

Office-safe fallbacks
- Lora -> Georgia
- DM Sans -> Arial or Helvetica

The deck is built at 16:9 and uses native PowerPoint text, shapes, charts and tables.
